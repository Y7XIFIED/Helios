Welcome to Helios, a tactile digital archive and interactive web system crafted by Y7XIFIED. Blending retro mechanical aesthetics with fluid modern web engineering, Helios features dynamic ink bleed canvas transitions, custom responsive grid architecture, and a persistent interactive directory dock.

## 🚀 Live Website
Experience the fully interactive website live here:
https://helioos.vercel.app

## 🎮 How to Control
- **Explore Sections**: Scroll naturally to glide across curated project showcases, technical notes, and deep system dives.
- **Interactive Directory Dock**: Click or tap the Directory hub button to open the branched navigation tree and instantly jump to any project or system node.
- **Tactile Theme Toggle**: Switch seamlessly between cream light mode and pitch black night mode using the tactile toggle in the top bar to trigger the ink-bleed canvas wave.
- **Audio & Project Notes**: Expand project drawers with the interactive tags to view architectural notes, source links, and live demos.

## ⚙️ Installation

### Prerequisites
- Node.js (v18.0.0 or higher recommended)
- npm (v9.0.0 or higher)

### Setup Instructions
1. Clone the repository:
```bash
git clone https://github.com/Y7XIFIED/Helios.git
cd Helios
```
2. Install dependencies:
```bash
npm install
```
3. Start the local server:
```bash
npm run dev
```

## 💻 Tech Stack
- **HTML5 & Modern CSS**: Fluid typography, CSS Grid, custom properties, and tactile mechanical borders.
- **JavaScript (ES Modules)**: Frame-rate independent wheel gliding, dynamic DOM micro-interactions, and reactive directory mounting.
- **WebGL & Canvas**: Shader-driven ink bleed transition engine with procedural noise maps.
- **Node.js**: Zero-dependency local development server with instant MIME resolution.
